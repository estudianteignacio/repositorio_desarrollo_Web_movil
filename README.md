Actualmente solo un FrontEnd que es capaz de simular las funciones de una página para una empresa de pastelería, además de carpetas de practica entre semanas, las cuales están basadas en temas vistos en clases.
El Frontend presente cuenta con la habilidad de simular el cambiar la cantidad de productos en un carrito, búsqueda de productos, inicio de sesión, cambio de detalles dentro de la cuenta de un usuario, además de contar con una presentación visual ya finalizada
EL Frontend **actualmente** no cuenta con Backend, ya que se esta siguiendo las instrucciones de los Talleres.

Cuanta con una pagina principal donde puedes dirigirte a las distintas areas con un carrusel de imagenes dentro de ella y un boton que te lleva a productos,productos cuanta con los distintos tipos de producto y una barra de busqueda de productos al presionar cada productos puedes ver los detalles, cuenta cuenta con el inicio de secion para clientes frecuentes, carrito cuenta el total de las tortas tambien ve el metodo de pago dirrecion, empresa cuanta con una descripcion de la empresa.
